# Data Analysis Portfolio Website

A clean and responsive portfolio website showcasing data analysis projects, technical skills, and professional experience.

## Live Demo

https://glaxxen.github.io/data-analysis-portfolio-site/

## Overview

This project is a modern portfolio website designed for data analysts to present their projects, technical expertise, and career achievements in a professional and visually appealing format.

The website is lightweight, responsive, and built using only HTML, CSS, and JavaScript, making it easy to customise and deploy.

## Features

- Responsive design
- Professional portfolio layout
- Project showcase section
- Skills section
- About section
- Contact section
- Smooth scrolling
- Lightweight and fast
- No external frameworks

## Project Structure

```text
.
```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/glaxxen/project-data-analysis-portfolio-site.git
```

Open `index.html` in your preferred web browser.

No installation or build process is required.

## Technologies

- HTML5
- CSS3
- JavaScript

## Customisation

You can easily personalise the portfolio by editing:

- `index.html` — Website content
- `style.css` — Styling and layout
- `main.js` — Interactive functionality
- `dp.png` — Profile image
